# Futuros proyectos

Ideas reservadas para después de estabilizar y validar Solutec POS.

## Sistema para gimnasios

Aplicación sencilla para gimnasios pequeños y medianos, con una experiencia clara para el dueño y el personal.

### Funciones iniciales

- Registro de miembros.
- Foto del miembro.
- Datos de contacto.
- Plan o mensualidad contratada.
- Fecha de inicio y vencimiento.
- Estado visible: activo, por vencer o vencido.
- Registro de pagos.
- Historial de asistencias.
- Búsqueda rápida por nombre, teléfono o código.
- Avisos de mensualidades próximas a vencer.
- Control de quién debe pagar y cuánto.
- Panel del dueño con ingresos del día, mes y año.
- Aplicación móvil opcional para consultar miembros, pagos y vencimientos.

### Enfoque del producto

- Interfaz simple, con términos fáciles de entender.
- Funcionamiento local aunque no haya internet.
- Respaldos automáticos.
- Sin contabilidad complicada en la primera versión.
- Crecimiento posterior hacia varias sedes y sincronización.

## Orden recomendado

1. Terminar y validar Solutec POS en una tienda real.
2. Corregir los bugs encontrados durante las pruebas manuales.
3. Preparar la versión piloto y el proceso de instalación.
4. Diseñar la arquitectura compartida para futuras aplicaciones.
5. Crear el sistema de gimnasios como un producto independiente.
